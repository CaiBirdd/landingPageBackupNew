### 亮点 3：UTM 参数归因与 Session 管理

**业务背景**：用户通过 Facebook 广告点击进入落地页，URL 携带 UTM 参数，需要将广告来源与用户行为关联追踪。

**实现流程**：
```
用户点击广告 → URL 携带 UTM 参数 → 前端解析参数 → 发送后端生成 session_id
     → localStorage 存储 → 后续表单提交携带 session_id → 形成完整归因链路
```

**实现代码** (`recordUtmParams.js`)：
```javascript
const getUrlParams = () => {
  const params = new URLSearchParams(window.location.search)
  const utmParams = { device: getDeviceType() }
  
  if (params.get('campaign_name')) utmParams.campaign_name = params.get('campaign_name')
  if (params.get('adset_name')) utmParams.adset_name = params.get('adset_name')
  if (params.get('ad_name')) utmParams.ad_name = params.get('ad_name')
  if (params.get('ad_content')) utmParams.ad_content = params.get('ad_content')
  // ...
  return utmParams
}

const recordUtmParams = async () => {
  const utmParams = getUrlParams()
  const hasUtmParams = Object.keys(utmParams).length > 1
  if (!hasUtmParams) return
  
  const res = await recordUtmParamsAPI(utmParams)
  if (res.data?.session_id) {
    localStorage.setItem('session_id', res.data.session_id)
  }
}
```

**追踪维度**：
| 参数 | 说明 | 示例值 |
|------|------|--------|
| `campaign_name` | 广告活动名称 | Meeting_Strategist_ManualAndAI |
| `adset_name` | 广告组名称 | function_AI |
| `ad_name` | 广告名称 | function_AI |
| `ad_content` | 广告内容类型 | function / painpoint |

**Facebook Pixel - useFbPixel Composable 封装**：

基于 Vue 3 Composition API 封装的 Facebook Pixel 追踪模块，提供统一的广告转化追踪接口：

```javascript
// composables/useFbPixel.js
export function useFbPixel() {
  // 检查 fbq 是否可用（防止 SSR 或 SDK 未加载时报错）
  const isFbqAvailable = () => {
    return typeof window !== 'undefined' && typeof window.fbq === 'function'
  }

  // 追踪标准事件（带错误处理）
  const track = (eventName, params = {}) => {
    if (isFbqAvailable()) {
      try {
        window.fbq('track', eventName, params)
        console.log(`[FB Pixel] Tracked: ${eventName}`, params)
      } catch (error) {
        console.error('[FB Pixel] Track error:', error)
      }
    } else {
      console.warn('[FB Pixel] fbq is not available')
    }
  }

  // 追踪自定义事件
  const trackCustom = (eventName, params = {}) => {
    if (isFbqAvailable()) {
      window.fbq('trackCustom', eventName, params)
    }
  }

  // 常用标准事件快捷方法
  const trackLead = (params = {}) => track('Lead', params)
  const trackCompleteRegistration = (params = {}) => track('CompleteRegistration', params)
  const trackContact = (params = {}) => track('Contact', params)

  return { track, trackCustom, trackLead, trackCompleteRegistration, trackContact, isFbqAvailable }
}
```

**调用示例**：
```javascript
const { trackLead } = useFbPixel()

trackLead({
  content_name: 'Email Submission',
  content_category: 'Lead',
  value: 1.00,
  currency: 'USD'
})
```

**设计优势**：
- ✅ 防御性编程：`isFbqAvailable()` 检查避免 SDK 未加载时报错
- ✅ 统一接口：标准事件和自定义事件使用统一 API
- ✅ 快捷方法：常用事件（Lead/Registration/Contact）封装为快捷函数
- ✅ 调试友好：开发环境下打印追踪日志

**埋点事件清单**：

### 亮点 5：完善的错误处理与用户反馈机制

**技术方案**：分层错误处理 + 分状态埋点 + 友好用户提示

**实现代码** (`FeedbackForm.vue`)：
```javascript
const sendData = async (data, submitType) => {
  try {
    const res = await createFeedbackAPI(data)
    
    // ========== 成功响应 ==========
    if (res.status === 201) {
      toast.success(submitType === 'email' 
        ? 'Email submission successful!'

      // 成功埋点
      posthog.capture('feedback_submitted', { ... })

      // ========== 非 201 状态码 ==========

        error_status: res.status,
        submit_type: submitType
      })
    }
  } catch (error) {
    // ========== 网络错误或其他异常 ==========
    toast.warning('Submission failed, please check your network.')
    posthog.capture('feedback_submit_error', {
      error_message: error.message,
      submit_type: submitType
    })
  }
}
```

**业务背景**：CVR (Conversion Rate) 是衡量广告投放效果的核心指标。

**实现代码** (`FeedbackDataManagement.vue`)：
```javascript
// 有邮箱或反馈的条数（有效转化）
const hasEmailOrFeedback = computed(() => {
  return allData.value.filter(
    item => item.email !== '未提交' || item.feedback !== '未提交'
  ).length
})

// CVR = 有效转化数 / 总访问数 × 100%
const cvr = computed(() => {
  return total.value > 0 
    ? ((hasEmailOrFeedback.value / total.value) * 100).toFixed(2) 
    : '0.0'
})
```

### 亮点 2：线索质量分层统计

**业务背景**：运营需要快速识别高价值线索（留了邮箱）vs 无效点击（仅 UTM）。

**实现代码**：
```javascript
// 仅 UTM（无效点击）
const utmOnly = computed(() => {
  return allData.value.filter(
    item => item.email === '未提交' && item.feedback === '未提交'
  ).length
})

// 仅邮箱（标准线索）
const emailOnly = computed(() => {
  return allData.value.filter(
    item => item.email !== '未提交' && item.feedback === '未提交'
  ).length
})

// 邮箱 + 反馈（高价值线索）
const emailAndFeedback = computed(() => {
  return allData.value.filter(
    item => item.email !== '未提交' && item.feedback !== '未提交'
  ).length
})
```

**分层展示**：
```html

<el-tag type="success">仅邮箱: {{ emailOnly }}</el-tag>
```

### 亮点 4：全量数据排序与分页

**技术挑战**：Element Plus 表格默认只对当前页数据排序，需要实现全量数据排序后重新分页。

**实现代码**：
```javascript
const applySortAndPagination = () => {
  let sortData = [...allData.value]

  // 根据条件对全量数据排序
  if (sortProp.value && sortOrder.value) {
    sortData = sortData.sort((a, b) => {
      let aVal = a[sortProp.value]
      let bVal = b[sortProp.value]

      if (sortProp.value === 'createTime') {
        aVal = new Date(aVal)
        bVal = new Date(bVal)
      }

      if (sortOrder.value === 'ascending') {
        return aVal > bVal ? 1 : aVal < bVal ? -1 : 0
      }
      return aVal < bVal ? 1 : aVal > bVal ? -1 : 0
    })
  }

  // 排序后重新分页
  const start = (pagination.value.page - 1) * pagination.value.pageSize
  const end = start + pagination.value.pageSize
  tableData.value = sortData.slice(start, end)
}
```

## 📝 简历项目介绍（推荐版）

### 项目名称
**AI 会议助手（SynapNote）营销落地页与运营数据系统**

### 技术栈
Vue 3 + Vite + Vant UI + Element Plus + PostHog + Docker + Nginx

### 项目描述
负责 AI SaaS 产品营销系统的前端开发，涵盖用户获取落地页与运营数据分析面板。基于 Vue 3 构建响应式架构，实现从广告投放到用户转化的完整数据闭环，有效支撑产品的早期用户获取与广告投放优化。

### 核心产出（三大亮点）

**亮点一：多端架构与响应式适配（来自落地页项目）**
> 采用**组件级分流策略**处理 PC/Mobile 差异化交互，移动端基于 `postcss-pxtorem` 与**动态 REM 方案**实现像素级还原，确保多终端一致性体验。

**亮点二：营销数据闭环与全链路追踪（来自落地页项目）**
> 独立封装 **UTM 参数解析模块**，将广告来源与后端 Session ID 自动绑定，结合 PostHog 自定义埋点，打通"**流量来源-用户行为-转化归因**"的全链路数据监测。

**亮点三：运营决策面板与 A/B 测试分析（来自数据面板项目）**
> 独立开发运营决策看板，集成**实时 CVR（转化率）计算**与**线索分层清洗**功能，通过对广告素材与落地页变体的**多维度 A/B 测试分析**，辅助团队量化评估"人工 vs AI"投放策略并优化 ROI。
